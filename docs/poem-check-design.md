## 0. 功能概述

新增页面：用户**粘贴自己的诗作**，应用：

1. 展示逐字**平仄**与句末**韵脚**（复用现有标注渲染）；
2. 自动判定**体裁**（近体诗：五绝/七绝/五律/七律）；
3. 若属近体诗，做**格律检测**并给出提示（如**孤平**、三平尾、失对、失粘、出韵等）；
4. 非近体诗（古体/词）仅展示平仄韵脚，不做格律提示。

## 1. 入口与页面

- 入口：书架页顶栏新增「校验」入口（或 FAB 快捷菜单），进入独立页面。
- 页面 `PoemCheckScreen`：
  - 上部：多行输入框（粘贴诗作）；
  - 「分析」按钮；
  - 结果区：诗作 + 平仄/韵脚标注（复用 `AnnotatedPoemBody`）；
  - 下方：**格律提示列表**（每条含句号/字位/说明）；
  - 体裁自动识别结果展示（可下拉手动纠正）。

## 2. 引擎设计（`:engine`）

### 2.1 体裁识别

```
detectForm(contentText): String?   // 五言绝句/七言律诗/... 或 null（非近体诗）
```
- 按标点切句，剔除标点后取每句字数；
- 全部句同长（5 或 7 字）+ 句数 4 → 绝句；8 → 律诗；否则 null（古体/词/杂言）。

### 2.2 格律检测 `PingZeChecker`

```
data class PingZeIssue(
    val lineIndex: Int,   // 第几句（0-based）
    val charIndex: Int?,  // 字位（可选，用于定位）
    val type: IssueType,
    val message: String,
)
enum class IssueType { LONELY_LEVEL, TRIPLE_LEVEL_TAIL, TRIPLE_OBLIQUE_TAIL,
                       MISMATCH_IN_COUPLET, MISMATCH_BETWEEN_COUPLETS, RHYME_MISMATCH }
```

检测规则（仅近体诗）：

| 规则 | 判定 | 提示文案示例 |
| --- | --- | --- |
| **孤平** | 平收句（韵脚句）去掉末字后，平声数 == 1 | 「第 3 句犯孤平：句中仅一个平声字」 |
| 三平尾 | 句末三字全平 | 「第 1 句三平尾（句末三字皆平）」 |
| 三仄尾 | 句末三字全仄 | 「第 2 句三仄尾（句末三字皆仄）」 |
| 失对 | 一联内两句在二四（六）位平仄不相反 | 「第 1 联失对：二四（六）位平仄未相对」 |
| 失粘 | 相邻两联在二四位平仄不相粘 | 「第 2 联与第 1 联失粘」 |
| 出韵 | 韵脚字韵部与首韵脚不一致 | 「第 X 句韵脚『字』韵部（Y）与首韵（Z）不同」 |

- UNKNOWN（待考）字：跳过其对位判断，并在结果区提示"若干字无法判定平仄"。
- 押韵提示：近体诗默认押平声韵，若韵脚字为仄，提示"押仄声韵（近体诗通常押平韵）"（信息性）。

### 2.3 依赖与复用

- 复用 `PingZeEngine` 产出 `AnnotatedPoem`（平仄/韵脚/韵部）；
- `PingZeChecker.check(annotated, form)` 纯函数，可单测。

## 3. UI 细节

- 平仄/韵脚展示复用 `AnnotatedPoemBody`（横排），无需新排版组件。
- 格律提示列表：按句号分组，问题字可用朱砂标注；每条点击可定位到对应句。
- 空态/错误态：未粘贴 / 非近体诗（提示"该作品非近体诗，仅展示平仄韵脚"）。

---

## 4. 局限与边界（如实标注）

- 仅对**近体诗**做格律检测；古体/词/曲不适用（不做强判）。
- **孤平**规则按"平收句仅一平"判定，涵盖五言/七言常见情况；拗救（本句自救、对句相救）暂不识别，可作后续增强。
- **多音字 / 入声字**：平仄按诗韵新编判定，入声字按仄（与阅读页一致）；个别字可能判定存疑（见 known-issues）。
- 输入需规范标点（。，）以便切句；无标点输入会合并成一句，提示用户。
