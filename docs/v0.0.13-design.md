## 1. Bug：平仄标记在圆底中偏下

### 现状

`ToneMarkBadge`（AnnotatedPoemView.kt）用 `Box + Text` 绘制：

- 平 → `〇`（U+3007）
- 仄 → `●`（U+25CF）
- 待考 → `？`

`Box` 的 `contentAlignment = Center` 居中的是**文本盒**，但 `〇`/`●` 符号字形按**基线**绘制，墨迹落在 em 盒下半部，视觉偏下。

### 方案

- **SYMBOL 模式**（〇●）改用 Compose `Canvas` 绘制，几何上与圆底**同心**：
  - 平：`drawCircle` 描边圆；
  - 仄：`drawCircle` 实心圆；
  - 待考：实心小圆 + 文字「？」（中文居中正常）。
- **TEXT 模式**（平/仄/？）保留 `Text`。
- 图例 `ToneMarkLegend`/`LegendItem` 复用同一 Badge 绘制。
- 抽取 `ToneBadgeContent(tone, style, size)`，`ToneMarkBadge` 与图例均调用。

### 验收

- 任意字号（18–34sp）下标记与圆底同心、无偏移；横排与图例表现一致。

## 2. 本地语料扩充（诗经 → 清诗）

### 2.1 数据源

**chinese-poetry 开源数据集**（[github.com/chinese-poetry/chinese-poetry](https://github.com/chinese-poetry/chinese-poetry)，MIT 协议）——与现网已验证可访问的同一来源。

### 2.2 覆盖范围（全量为主）

| 集 | 来源（chinese-poetry） | 规模 |
| --- | --- | --- |
| 诗经 | `诗经/` 全部 | ~305 |
| 楚辞 | `楚辞/` | ~30 |
| 汉魏六朝 | `曹操诗集/` 等 | ~60 |
| 全唐诗 | `全唐诗/` **全量** | ~57,000 |
| 宋词 | `宋词/` **全量** | ~21,000 |
| 元曲 | `元曲/` 选 | ~1,000 |
| 清词 | `纳兰性德/` | ~340 |

- 总量目标：**约 8 万首**，原始 JSON ~60MB，APK 内 gzip 后约 +15–20MB。
- 以全量为原则；体积/启动为已知成本（见 §2.4）。

### 2.3 数据加工（构建期一次性脚本，不入 app 包）

- 从 GitHub 拉取上述集合（sparse clone）→ 统一转换 `PoemSeed`
  `{ title, author, dynasty, form, content }`；
- 繁体 → 简体（`OpenCC`）；
- 清洗：去重（title+author）、剔空正文、格式归并；
- 输出**按集拆分**的多个 JSON 到 `assets/corpus/`（如 `shijing.json`、`tang.json`、`song_ci.json`…），便于管理与按需加载；
- 保留精选种子 `poems.json`（首启入书架，可选扩到 50–100 首）。

### 2.4 运行时与性能

- `CorpusLoader` 按集 lazy 加载、内存合并为搜索源（8 万首内存解析约 40–60MB，可接受；真机实测）。
- `AddViewModel` 防抖 + 标题/作者 `contains` 不变；若真机搜索明显变慢，后续可迭代为 Room 索引。
- 加入书架后由 `PingZeEngine` 现场标注。

### 2.5 验收

- `make test` 全绿；搜索可命中跨朝代（诗经/全唐/宋词/元曲/清）；
- APK 体积、冷启动、搜索耗时在真机实测并记录。

## 3. 书架列表增强（排序 + 按作者折叠）

### 3.1 排序（SortOrder）

| 排序 | 实现 |
| --- | --- |
| 添加时间（新→旧） | `addedAt DESC`（默认，现状） |
| 添加时间（旧→新） | `addedAt ASC` |
| 标题首字母 | 拼音（TinyPinyin） |
| 作者首字母 | 拼音 |
| 朝代 | 朝代顺序表 |
| 体裁 | 体裁顺序表 |

- 顶部排序入口（菜单/弹层），选择后立即重排；排序在 ViewModel 层做。

### 3.2 拼音支持

- 新增依赖 `TinyPinyin`（离线、轻量）；
- `PoemEntity` 增加 `titlePinyin`、`authorPinyin` 列（插入时计算）；
- Room 迁移：新增列 + 回填（或测试期 `fallbackToDestructiveMigration`）。

### 3.3 按作者折叠

- 按作者分组：组头 = 作者（含作品数），点击展开/收起；
- 与排序组合：按作者首字母时天然按作者分组折叠。
